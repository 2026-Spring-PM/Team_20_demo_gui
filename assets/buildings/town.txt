# =============================================================================
# town.txt -- placements for buildings in the Town District (5/19 dev item 1).
#
# The town is a separate scene from the village; PlayState swaps the
# active TileMap + BuildingRegistry + NPC list when the player walks the
# travel stone. The buildings here are decorative (no recipes, no
# NPCs) -- the gameplay anchors are the registered NPCs ("Iola" the
# special vendor, "Marlow" the gambler, "Z" the return travel stone)
# placed via assets/maps/town.txt.
#
# Format (same as village.txt):
#   <kind>  pos=<tx,ty>  size=<w,h>  door=<tx,ty>  [npc=<marker>]
#
# Coordinates are in TILE units (multiplied by TILE_SIZE in
# BuildingRegistry). The town is 60x40 tiles. Building sizes here are
# intentionally village-scale (5x5 to 10x4 tiles) so the town feels as
# populated as the home village rather than a half-empty plaza.
#
# Layout (text sketch -- left = west, top = north):
#
#     row 2-7:     [ House1 ] [ House2 ]   [  TallHouse  ]  [ House3 ]
#     row 12:                X (Iola)
#     row 15-18:             [Fountain]
#     row 22:                G (Marlow)
#     row 28:                Z (return stone)
#     row 30-35:   [ House4 ] [ House5 ]   [ TallHouse2 ]   [ House6 ]
#
# All buildings are decorative -- no NPC marker -- so the player walks
# AROUND them but they don't open popups. The collider is the
# building's full rect.
# =============================================================================
