# 5/24 redesign: village map is now 80x60 (wider than tall). Buildings
# cluster in the WEST column (col 1-18) and EAST column (col 61-78); the
# central band col 19-60 row 1-29 is plaza / grass / paths and below
# (row 30-58) is the 40-plot farm (8 wide x 5 rows of plots, 5x5 each,
# with a 1-tile path between each plot row at rows 35/41/47/53).
#
# Format (one building per non-blank, non-`#` line):
#   <kind>  pos=<tx,ty>  size=<w,h>  door=<tx,ty>  [npc=<id>]  [interior=<id>]
#
# All x/y/w/h are in TILE units. `npc=<id>` attaches an NPC to the
# building -- the id matches a section header in
# assets/npcs/definitions.txt. When a building has no `interior=`
# field, the NPC spawns at the door tile (one tile outside the
# building, in the door direction). When `interior=<id>` is set,
# the NPC lives INSIDE the matching interior map at
# assets/maps/interiors/<id>.txt; the door tile then becomes an
# enter-trigger (player presses E next to it to step inside).
# =============================================================================
