# =============================================================================
# bran.txt -- Bran the Village Merchant's shop catalog.
#
# Format (one entry per non-blank, non-`#` line):
#   <kind>  <id>  [at_village_lv=<n>]
#
# <kind>:
#   seed     A crop seed item. Auto-gated by CropDef::unlockLevel (the
#            village level must be >= the crop's unlock level).
#   animal   A livestock entry. Adds "<kind> (baby)" to the buy list.
#            Use at_village_lv=N to gate behind a village level (this
#            mirrors the old addLateAnimal() in ShopPopup.cpp).
#   item     A generic ItemId (gear, potions, magic stones, etc.).
#            Equipment items are auto-hidden if already owned.
#
# <id> is the canonical name string of the ItemId / AnimalKind enum value
# (case-sensitive, e.g. WheatSeed, BronzeSword, Cow).
#
# Prices are sourced from ItemDef::basePrice / AnimalDef::buyPriceCol so
# this catalog only declares WHAT is for sale, not at what price.
#
# title is the popup header text. If omitted, the merchant's name is used.
# =============================================================================
