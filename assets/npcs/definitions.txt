# =============================================================================
# definitions.txt -- catalog of every NPC identity that can exist in game.
#
# Each [section] declares one NPC. The section header is the NPC's stable
# ID, used everywhere: building files reference NPCs by ID (`npc=agnes`),
# placement files reference NPCs by ID, code looks up NPCs by ID via
# findNpcDefById().
#
# Required fields:
#   name      Display name shown above the NPC and in dialog headers.
#   role      Semantic role; maps to the NpcRole enum in NpcRegistry.h.
#             Determines (a) which NPC subclass is instantiated and
#             (b) which interact branch fires when the player presses E.
#
# Optional fields:
#   title     Subtitle / occupation (e.g. "Merchant"). Currently informational.
#   color     RGB triple "r, g, b" (0-255 each).
#   shop      For Merchant / RareGoodsMerchant / WanderingMerchant roles:
#             the ID of the shop file (assets/shops/<id>.txt) to load.
#   building  For Production / BuildingUpgrade roles: which BuildingKind
#             this NPC is tied to (e.g. Mill, Bakery, Winery, Dairy).
#   dialog    One dialog line. Repeat for multiple. Shown in rotation by
#             InteractiveNpc; ignored for Shop / Production / Decorative.
#
# Notes:
#   - Decorative villagers all share one definition ('villager'); their
#     palette colour is rotated at spawn time by PlayState.
#   - Knight is the player and has no NPC entity; only its role
#     (`Player`) matters so the spawn loop knows to set playerStart.
# =============================================================================
